# 3. Problem Statement

Camouflaged objects are difficult to detect because their colors, textures, and patterns are very similar to their backgrounds.

For example:
- A brown moth hiding on brown tree bark.
- A frog blending into green leaves.
- An insect hiding among dry leaves.
- A fish blending into the ocean floor.

Traditional image-processing techniques may struggle because the difference between an object and its surroundings is very subtle.

Our project aims to identify the hidden object at pixel level.

Instead of generating only a bounding box, the model should generate a **segmentation mask** indicating which pixels belong to the object.

# 4. Existing FINet Model

The original FINet model is a lightweight, frequency-based camouflaged object segmentation network.

According to the original research, FINet contains approximately **3.74 million parameters**.

The paper reports high benchmark inference speed, but those published numbers must never be represented as measurements from our application.

FINet combines spatial features and frequency information.

## Main Components

### A. Spatial Feature Extraction

Uses the original FINet visual backbone, described in our proposal as EfficientNet-B0.

Extracts spatial information such as shapes, textures, edges, and visual patterns.

### B. Frequency Feature Extraction

Uses Discrete Cosine Transform (DCT).

Frequency information provides complementary details about local texture, smooth regions, and image structure.

Our proposal describes YCbCr conversion and block-wise DCT. Inspect the actual source code and preserve its real preprocessing and tensor formats.

### C. Frequency Injection Module (FIM)

Combines spatial and frequency features.

Includes:
- HFIM: High-Frequency Injection Module.
- LFIM: Low-Frequency Injection Module.

### D. Asymmetric Decoder Block (ADB)

Processes the fused features and produces segmentation predictions.

Preserve the original implementation rather than building a simplified substitute.

### E. Segmentation Output

Produces a predicted object probability mask that can be visualized as:
- Grayscale probability mask.
- Binary segmentation mask.
- Colored mask overlay on the original image.

# 5. Our Proposed Research Contribution

Our proposed research contribution is **Differentiable Boundary Supervision**.

We want to investigate whether introducing an additional boundary loss during training improves segmentation of fine object outlines.

Examples include butterfly antennae, insect legs, and unclear boundaries where the foreground blends into the background.

This is a research hypothesis, not a guaranteed improvement.

## Original FINet Training

The official implementation uses a structure loss based on weighted Binary Cross-Entropy and weighted Intersection over Union.

Preserve the original loss and its supervision of multiple model outputs.

## Proposed Boundary-Aware Training

Introduce an additional boundary loss.

The predicted object mask is represented by probability map P.

Calculate the predicted boundary using:

B_pred = MaxPool(P) - MinPool(P)

Implement minimum pooling using a differentiable equivalent, such as the negative of maximum pooling applied to the negative input.

Generate ground-truth boundary targets from the ground-truth segmentation masks using a clearly documented morphological operation.

Compare the predicted boundary and ground-truth boundary using:

L_boundary = L_BCE + L_Dice

The proposed combined training objective is:

L_total = L_structure + lambda * L_boundary

Where:
- L_structure is the original FINet structure loss.
- L_boundary is the additional boundary loss.
- lambda controls the contribution of boundary supervision.

## Important Implementation Requirements

1. Do not introduce unnecessary new neural-network layers.
2. Preserve the original inference architecture.
3. Boundary supervision should operate during training only.
4. Ensure the predicted-boundary calculation supports backpropagation.
5. Implement unit tests proving gradients reach the model's predictions.
6. Support lambda = 0 to reproduce baseline training.
7. Allow lambda to be configured for experiments.
8. Validate numerical stability and boundary tensor dimensions.
9. Investigate kernel size and lambda values using validation data.
10. Do not claim boundary accuracy is improved until experiments establish it.

The goal is to improve boundary segmentation without adding learned parameters or boundary-loss computation during inference.
